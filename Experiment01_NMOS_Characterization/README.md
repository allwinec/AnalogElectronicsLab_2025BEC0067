
# Experiment 01 - NMOS Characterization

## Aim
To characterize an NMOS transistor using Cadence Virtuoso and obtain its DC characteristics.

## Software Used
- Cadence Virtuoso
- ADE-L
- Spectre

## Experiment
This experiment includes:

- NMOS schematic
- Simulation setup
- Parametric sweep
- DC operating point
- VGS transfer characteristic
- VDS output characteristics

## Results
The NMOS characteristics were obtained using DC analysis in Cadence Virtuoso.
